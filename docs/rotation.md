# 다심볼 로테이션 리포트 — 횡단면 전략

**대상:** 밈코인 28종(탐색 14 / 확인 14) · 15분봉 · 2024-09-01 ~ 2026-08-15
**비용:** 테이커 5bps + 슬리피지 2bps · 자본 공유 다심볼 백테스트
**엔진:** `src/crosssection.js` (테스트 18개)

이전: [meme-universe.md](meme-universe.md) · [hft-research.md](hft-research.md)

---

## 결론 (먼저)

**로테이션은 지금까지 만든 것 중 가장 좋은 결과를 냈고, 그리고 재현되지 않았다.**

탐색 그룹에서 워크포워드 **+23.05%**(MDD 20.6%)로 게이트 5개 조건 중 4개를 통과했다. 같은 구간 균등보유는 -77.03%다. 확인 그룹에 그대로 던지니 **-44.84%**(MDD 72.0%)로 무너졌다.

**네 번째 재현 실패다.**

---

## 1. 무엇이 다른가 — 시계열과 횡단면

지금까지의 전략은 전부 **시계열**이었다. 한 심볼의 과거를 보고 그 심볼을 살지 말지 정한다.

로테이션은 질문이 다르다: **"지금 이 중 무엇이 가장 나은가."** 매 시점 N개 심볼을 룩백 수익률로 줄 세워 상위 K개를 롱, (옵션) 하위 K개를 숏으로 잡는다. 시계열 전략이 전부 실패한 것과 **독립적인 가설**이라 시도할 값이 있었다.

엔진도 새로 만들어야 했다. 기존 엔진은 한 심볼에 자본 전체를 걸지만, 로테이션은 여러 심볼이 자본을 나눠 쓴다. 단일 심볼에 100% 비중을 주면 기존 엔진과 자산곡선이 **정확히 일치**하는 동치 테스트로 규약 이탈을 막았다.

## 2. 1차 실패는 신호가 아니라 회전율이었다

첫 실측은 **-98.71%**였다. 원인을 분해했다.

| 리밸런싱 주기 | 수익 | MDD | 리밸런싱 | 회전율 |
|---|---:|---:|---:|---:|
| 1봉마다 (15분) | **-99.09%** | 99.3% | 3,087회 | **650.9x** |
| 96봉마다 (1일) | -86.21% | 90.9% | 223회 | 105.2x |
| 672봉마다 (1주) | -87.00% | 93.3% | 49회 | 31.8x |
| 2688봉마다 (4주) | -79.17% | 87.4% | 14회 | 10.0x |

15분마다 순위를 다시 매기니 상위 종목이 계속 바뀌어 **회전율 688배**가 나왔다. 왕복 7bps를 688번 물면 원금의 48%가 수수료로 사라진다.

**순위를 매기는 주기와 갈아타는 주기를 분리**하고 주기를 학습 대상에 넣자 탐색 그룹 결과가 -98.71% → **+23.05%**로 뒤집혔다. 신호가 아니라 실행 빈도가 문제였던 첫 사례다.

## 3. 결과 — 탐색은 최고, 확인은 실패

| | 탐색 (meme-a) | 확인 (meme-b) |
|---|---:|---:|
| 워크포워드 수익 | **+23.05%** | **-44.84%** |
| 최대낙폭 | **20.6%** | 72.0% |
| 샤프 | 0.69 | -0.16 |
| 워크포워드 효율 | 0.05 | -0.08 |
| 리밸런싱 / 회전율 | 45회 / 63.7x | 52회 / 50.3x |
| 균등보유 기준선 | -77.03% | -60.23% |
| **게이트** | ❌ 4/5 (WFE만 미달) | ❌ 2/5 |

탐색 그룹만 보면 이 프로젝트에서 나온 최고의 결과다. 플러스 수익, 낮은 낙폭, 기준선 대비 100%p 초과. **그리고 확인 그룹에서 무너졌다.**

### 눈여겨볼 것 — 기준선은 두 그룹 모두 이겼다

| | 로테이션 | 균등보유 | 차이 |
|---|---:|---:|---:|
| meme-a | +23.05% | -77.03% | +100.1%p |
| meme-b | -44.84% | -60.23% | +15.4%p |

로테이션은 **양쪽 모두 균등보유를 이겼다.** 그러나 확인 그룹에서는 여전히 마이너스다. 게이트가 "플러스 수익"과 "기준선 초과"를 **둘 다** 요구하는 이유가 여기 있다 — 덜 잃는 것은 수익이 아니다.

### WFE는 두 그룹 모두 0 근처였다

탐색 그룹조차 WFE 0.05였다. 즉 **+23.05%는 학습 구간 성과가 검증 구간으로 이어진 결과가 아니었다.** 그 신호가 이미 있었는데, 총수익이 좋아 보여서 그것만으로 판단했다면 놓쳤을 것이다. 게이트에 WFE를 넣어둔 것이 여기서 값을 했다.

## 4. 네 번째 재현 실패 — 패턴이 이제 확실하다

| 라운드 | 가설 | 탐색 결과 | 확인 결과 |
|---|---|---:|---:|
| 2 | emaCross가 4h에서 통과 | 2/3 | **1/6 기각** |
| 3 | emaCrossLS가 4h에서 통과 | 3/6 | **2/6 기각** |
| 확인 | volBreakout이 1d에서 통과 | 1/9 | **0/9 기각** |
| **이번** | **로테이션이 밈코인에서 통과** | **4/5 조건** | **2/5 기각** |

네 번 모두 탐색 라운드 1등이 손대지 않은 데이터에서 무너졌다. **탐색 순위는 엣지의 순위가 아니라 그 구간에 우연히 맞은 정도의 순위**라는 것이 이제 네 번 확인됐다.

이번이 특히 중요한 이유: **가장 그럴듯했기 때문이다.** +23%, MDD 20%, 기준선 대비 100%p — 확인 라운드가 없었다면 여기서 시드를 넣었을 것이다.

## 5. 게이트 판정

| 조건 | 탐색 | 확인 |
|---|---|---|
| 이어붙인 워크포워드 곡선 플러스 | ✅ | ❌ |
| 기준선(균등보유) 초과 | ✅ | ✅ |
| MDD ≤ 35% | ✅ | ❌ (72.0%) |
| WFE ≥ 0.2 | ❌ (0.05) | ❌ (-0.08) |
| 리밸런싱 ≥ 30 | ✅ | ✅ |

**시드를 투입할 근거가 없다.**

## 6. 남긴 것

1. **엔진은 자산이다.** `src/crosssection.js`는 다심볼 자본 공유 백테스트를 정확히 수행하며(단일 자산 엔진과 동치 검증), 랩 제품에서 그대로 쓸 수 있다. 실패한 것은 이 특정 가설이지 엔진이 아니다.
2. **회전율 분해는 재사용 가능한 진단이다.** "신호는 괜찮은데 실행 빈도가 죽인다"는 패턴을 처음으로 잡아냈고, 같은 분해를 다른 전략에도 적용할 수 있다.
3. **WFE가 총수익보다 먼저 경고했다.** 탐색 그룹의 WFE 0.05는 +23%가 이어진 성과가 아님을 말하고 있었다. 다음부터는 총수익이 좋아도 WFE가 낮으면 확인 라운드 전에 기대치를 낮춘다.

## 7. 다음

밈코인 유니버스는 `meme-a`·`meme-b`를 모두 소진해 **깨끗한 확인 세트가 남아 있지 않다.** 여기서 새 가설을 시험하면 확인할 데이터가 없다.

남은 정직한 선택지:
1. **메이저·알트 유니버스로 로테이션 재시험** — 새 그룹을 미리 갈라 두고 탐색/확인을 다시 구성한다. 다만 이번 실패가 밈코인 특유의 문제인지 로테이션 자체의 문제인지는 이 결과만으로 알 수 없다.
2. **포지셔닝 데이터 축적 대기** — 2026-08-15부터 수집 중. 30일이 쌓이면 가격 파생이 아닌 입력으로 순위를 매길 수 있다.
3. **트레이딩 탐색 종료, 랩 제품에 집중** — 지금까지의 실패 기록 자체가 랩의 판매 근거다.
